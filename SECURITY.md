# Politique de sécurité

## Versions prises en charge

Seule la dernière version publiée de FitSearch reçoit les correctifs de
sécurité.

## Signaler une vulnérabilité

Ne publiez pas une vulnérabilité dans une issue publique.

Utilisez la fonction privée de signalement de vulnérabilité proposée dans
l’onglet **Security** du dépôt GitHub.

Décrivez si possible :

- la version concernée ;
- les conditions nécessaires pour reproduire le problème ;
- son impact potentiel ;
- les étapes de reproduction ;
- toute proposition de correction.

Aucun mot de passe, jeton, contenu privé ou donnée personnelle réelle ne doit
être joint au signalement.

## Traitement

Le signalement sera examiné avant toute publication publique. Un correctif
sera préparé et testé avant la diffusion coordonnée des informations utiles.
